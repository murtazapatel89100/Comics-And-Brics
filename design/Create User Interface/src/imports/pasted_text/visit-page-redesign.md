# COMICS & BRICS — REDESIGN THE VISIT EXPERIENCE
## VISIT + FRANCHISE DISCOVERY

Redesign the existing **VISIT** page of the Comics & Brics website.

The current public website already has an established visual identity.

The existing pages are:

- HOME
- EXPLORE
- GAMES
- VISIT

The EXPLORE experience is being redesigned separately into a discovery hub containing:

- Comics
- Legos
- Food
- Events

Games remains a dedicated page.

Now redesign the VISIT page so that it becomes a richer **"experience the cafe"** page rather than simply a location/hours page.

---

# IMPORTANT — THIS IS A REDESIGN OF VISIT

Unlike HOME and GAMES, the existing VISIT page is allowed to be substantially restructured.

However, preserve the overall Comics & Brics design language:

- Cream background
- Ink black
- Comic yellow
- Board-game blue
- Comic coral
- Fresh green
- Strong black borders
- Hard/compact shadows
- Bold editorial typography
- Phosphor Icons
- Clean, playful but professional visual style

Do not turn it into a generic cafe website.

---

# CORE PURPOSE

The Visit page should answer:

1. Where are Comics & Brics?
2. When can I visit?
3. What can I do there?
4. What can I see/play/read?
5. What franchises and worlds are represented?
6. What's happening soon?
7. How do I plan my visit?

The page should feel like an invitation to physically visit the cafe.

---

# 17. CONNECTION TO THE FUTURE ADMIN SYSTEM

Design the Visit page so that the future admin dashboard can manage its content.

Conceptually:

Admin creates event
→ event appears on Visit

Admin adds franchise
→ franchise appears on Visit

Admin associates a comic with a franchise
→ comic appears under that franchise

Admin adds LEGO set
→ LEGO appears under relevant franchise

Admin adds game
→ game appears under relevant franchise

Admin publishes content
→ content appears on relevant franchise page

Admin modifies daily specials
→ Food page updates

Do not implement this backend yet.

This is only the UI/content architecture.
