Design a polished, modern responsive website concept for **Comics & Brics Cafe, Pune** — a real-world café and community space centered around comics, manga, board games, and events.

This is a **small pitch/demo website**, so prioritize visual impact and clear storytelling over a huge number of pages.

## BRAND / VISUAL IDENTITY

Create a distinctive visual identity that combines:

* Modern independent café
* Comic-book culture
* Board-game community
* Editorial/magazine design
* Slight retro print/comic influence

Avoid generic superhero aesthetics, Marvel/DC branding, childish cartoon styling, or an overly busy gamer aesthetic.

### Color palette

* Deep Charcoal: #111111
* Warm Paper: #F5F1E8
* Comic Yellow: #FFD23F
* Electric Blue: #3B82F6
* White: #FFFFFF
* Muted Gray: #6B6B6B

Use warm paper as the primary light background, charcoal for typography and navigation, yellow as the signature accent, and blue sparingly for secondary highlights.

### Typography

Use **Space Grotesk** for headings, navigation, buttons, and large display text.
Use **Inter** for body copy and supporting information.

Headings should be bold and confident.
Use occasional uppercase labels with slightly increased letter spacing.

## DESIGN LANGUAGE

Use:

* 12–16px rounded cards
* 2px dark borders on important cards
* subtle offset shadows
* comic-panel inspired layouts
* halftone dot textures used very sparingly
* small sticker/badge elements
* occasional speech-bubble shapes
* large photography
* asymmetrical editorial layouts
* strong whitespace

The site should feel handmade and characterful while still being professionally designed.

Do NOT overuse comic-book effects, explosions, speed lines, or speech bubbles.

## RESPONSIVE DESIGN

Design desktop first at approximately 1440px width.

Also create a mobile version at 390px width for the homepage.

On mobile:

* hamburger navigation
* stacked hero
* horizontal scrolling category chips
* single-column cards
* large touch-friendly buttons

## IMPORTANT

This is a **pitch prototype**, not a complete production website.

Focus on:

1. Strong visual identity
2. The unique Comics & Brics experience
3. Comics discovery
4. Board-game discovery
5. Events/community
6. Getting someone to visit the café

Use realistic placeholder content and high-quality comic/café/board-game imagery.

Make the final result look like a website that could genuinely be launched by a premium independent café in Pune, rather than a generic AI-generated café template.
