# COMICS & BRICS — REDESIGN VISIT PAGE
## VISIT + FRANCHISE WORLDS

Redesign ONLY the existing **VISIT** page of the Comics & Brics website.

The Explore page has already been redesigned and is FINISHED.

DO NOT modify:
- HOME
- EXPLORE
- GAMES
- the global navigation
- the global footer
- existing design system unless required for the new Visit page

The only page being redesigned in this task is:

**VISIT**

---

# CORE IDEA

The current Visit page is primarily focused on practical visit information.

Redesign it so that it still helps someone plan their visit, but also communicates:

**WHAT CAN I EXPERIENCE AT COMICS & BRICS?**

A major new section should introduce **FRANCHISE WORLDS**.

The requirements for Comics & Brics include franchise-based information such as:

- Harry Potter
- Lord of the Rings
- etc.

The franchise section should make these worlds feel like part of the overall Comics & Brics experience.

---

# IMPORTANT — DO NOT TURN VISIT INTO EXPLORE

The Explore page is already the discovery hub for:

- Comics
- Legos
- Food
- Events

Do NOT duplicate the Explore page structure.

Visit should remain focused on:

**THE PHYSICAL C&B EXPERIENCE**

and:

**THE WORLDS / FRANCHISES YOU CAN DISCOVER AT C&B**
